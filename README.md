# Jom Kenal Huruf Al-Quran (web)
Jalankan: klik dua kali index.html (tiada pelayan atau pemasangan). Disyorkan Chrome/Edge/Safari terkini.
Deploy: muat naik seluruh folder ke hosting statik (Netlify Drop, Cloudflare Pages, GitHub Pages).
Struktur: index.html (enjin), data/slides.js + slides.json (peta slaid & butang), media/img, media/vid, media/bgm.m4a, NAVIGATION_MAP.md (peta & perkara perlu disahkan), validate.py.
Semakan pautan: `python3 validate.py` di dalam folder ini.
Kontrol: bar bawah — Kembali, Home (Galeri), Seterusnya, Pena/Pemadam/Padam Semua (slaid menulis), bunyi, Kemajuan. Papan kekunci: ← → Home.
Kemajuan & pilihan bunyi disimpan dalam localStorage.
